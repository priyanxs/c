🛠️ Classic <conio.h> Functions (Console I/O)

clrscr(): Clears the entire text screen and positions cursor at (1, 1).

getch(): Reads a single character from the keyboard without echoing it to the screen. Crucial in Turbo C++ to pause the user screen before returning to the IDE!

getche(): Same as getch(), but echoes the typed character to screen.

gotoxy(x, y): Moves cursor to column x (1 to 80) and line y (1 to 25).

textcolor(color): Sets foreground text color (0 to 15, e.g. YELLOW, RED, GREEN, WHITE).

textbackground(color): Sets background text color (0 to 7).

delay(milliseconds): Suspends execution for specified milliseconds (from <dos.h>).

🎨 Borland Graphics Interface (<graphics.h>)

initgraph(&gd, &gm, "C:\\TC\\BGI"): Initializes graphics hardware in EGA/VGA mode (usually 640x480 with 16 colors).

circle(x, y, radius): Draws a circle at center (x, y).

line(x1, y1, x2, y2): Draws a line from (x1, y1) to (x2, y2).

rectangle(left, top, right, bottom): Draws an unfilled rectangle.

setcolor(color): Sets current drawing color.

closegraph(): Deallocates memory used by graphics system and restores text mode.

💡 Why Turbo C++ is Unique (16-bit Architecture)

• 16-bit Integers: In Turbo C++, int is 16-bit (2 bytes), with values from -32,768 to 32,767. (Modern compilers use 32-bit/4 bytes).

• Header .h extension: Turbo C++ uses pre-standard C++ headers like #include <iostream.h> without using namespace std;.

• void main(): Permitted in Turbo C++ 3.0, whereas ISO C++ requires int main().
